Файлы для перевода старых плат ДОМОВОЙ на новую систему

Эту папку NextConfig находит сам. Оператору ничего выбирать не нужно:
кнопка «Перевести на новую систему» в окне старой платы ведёт по шагам.
Номер платы в новой системе у всех - 139.

v5\             плата ДОМОВОЙ NEXT v5 (старая прошивка 48)
  139.71.<сборка>.bin   новая прошивка
  DomovoiBoot.bin       новый загрузчик 0x32

старая_MODEM\   старая плата ДОМОВОЙ IP v1–v3, вариант MODEM (старая прошивка 45/47)
  139.71.<сборка>.bin   новая прошивка для этой разводки: второго реле нет,
                        PA0 (CTS порта RS232) не трогается. Платам v5 не давать.
  DomovoiBoot.bin       новый загрузчик 0x32, профиль MODEM
  140.71.<сборка>.bin   только для платы, на которую 29.09.2026 поставлен загрузчик 140:
                        с ней программа меняет загрузчик обратно на 139

Номер у v5 и старой MODEM одинаковый, поэтому NextConfig различает их по папке
и по модулю связи (v5 - SLM336, старые - Quectel).

Плата MINI (номер 11): новой прошивки для неё нет, перевод недоступен.
Загрузчик 0x32 работает только на микроконтроллере со 128 КБ памяти.

Собрано в IAR из репозитория прошивки, коммит f969e72: Release, Release_IPv3,
Release_140, загрузчик Release и Modem_Release.
