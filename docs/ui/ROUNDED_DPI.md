# Главный экран и чёткость, 14.10.2026

«Обслуживание» перенесено из «Сервиса» на «Устройство», после входов и выходов,
перед камерой. Перенесены существующие кнопки с обработчиками и подтверждениями.
На широком экране действия идут в ряд, на узком переносятся.
Общая тема рисует скруглённые карточки, кнопки и пункты навигации.

У открытого рабочего окна обнаружен SystemAware / 96 DPI, у новой сборки на
том же рабочем столе — PerMonitorV2 / 144 DPI. Старое окно растягивалось Windows.
App.config включает поддержку DPI в WinForms, после загрузки формы задаётся
база исходной раскладки и AutoScaleMode.Dpi. Порядок важен: смена AutoScaleMode
сбрасывает AutoScaleDimensions. Рисуемые графики используют DPI самого контрола.
Текст остаётся GDI, скругления рисуются векторно с антиалиасингом.

Настройка Framework: [High DPI support](https://learn.microsoft.com/en-us/dotnet/desktop/winforms/high-dpi-support-in-windows-forms).
