Исправления по аудиту NextConfig от 01.10.2026 (исходная версия 87081f8)

1. Обычная запись и запись значений по умолчанию требуют прочитанного блока 512 байт. Защита есть в UI и SetConfig; скрытые поля сохраняются.
2. Выбор файла прошивки больше не изменяет профиль старой MODEM при отмене и повторной попытке.
3. Проверка адресов использует текст ошибок, а не видимость меток; при ошибке открывается раздел связи.
4. Обмен проверяет номер и команду ответа, включая исходную команду в ACK, и продолжает ждать после постороннего кадра. Запросы получают сменяющиеся номера. Команды 100/101/106 совместимы с номером 0 в существующей прошивке.
5. Все активные пути записи загрузчика и фото используют конечный таймаут. Начальная настройка SerialPort также ограничивает запись.
6. Команды и фото освобождают паузу опроса через Finally при исключении.
7. PIN и APN маскируются в обоих направлениях обмена и в тексте подтверждения изменений. Старые журналы не изменялись.
8. TCP-ответ собирается потоковым декодером: длина, CRC, команда и достаточная длина полей проверяются до чтения. Подключение/чтение/запись ограничены; UI обновляется в своём потоке.
9. SetTime проверяет код результата ACK, а окно сообщает результат установки времени.
10. Неизвестный уровень сигнала (включая 99) больше не показывает полную шкалу.
11. Просроченные сетевые, входные, выходные и RS-485 индикаторы становятся нейтральными. Зависимые действия блокируются до свежего статуса, с учётом занятости фото.
12. Кнопки удаляются из статического кеша Theme при уничтожении.
13. Шкала фото рассчитана на 100 процентов.
14. Подтверждённый PIN обновляется после чтения/сохранения и передаётся повторному подключению, включая ведущие нули.

Проверки: сборка Release в bin/Review; audit-regression (71), protocol-regression (4), network-regression (17), sections-contract (10), oldfw-write (99), oldfw-read (70), oldfw-service (14), oldfw-numbers (19), oldfw-rfid (18), oldfw-installer (28), photo-read (28). Также прошли oldfw-security, oldfw-photo, test_rs485, test_ui_fields. Всего 378 нумерованных проверок плюс четыре дополнительных набора. git diff --check — без ошибок.

Границы проверки: автоматические тесты не открывают COM-порты, не прошивают плату, не меняют её настройки и не отправляют команды боевому TCP-серверу. Протокол/profile тест компилирует проверяемые методы со stub-транспортом. На старых ответах 100/101/106 номер всегда 0, поэтому отличить два запоздалых ответа одной такой команды по номеру невозможно.

Исходное сообщение «Нет интернета» отражает статус модема контроллера. Исправления устраняют найденные ошибки конфигуратора, но не доказывают исправность SIM, APN, оператора, питания или модема. Отсутствие других дефектов не гарантируется.
