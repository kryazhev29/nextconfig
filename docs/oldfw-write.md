# Запись старой прошивки

Основа: 60270a0, маскирование журнала сохранено. Запись разрешена только для
45/47/48 по указанию владельца; другие номера — чтение, 49 — NEXT.

## Этап 2 — настройки

Все содержательные поля ParseSettings редактируются отдельным диалогом,
включая расписания (двойной щелчок). Числовые коды не заменяются первым
пунктом списка. Резерв 195–509 остаётся исходным, CRC рассчитывается.
UInt16/UInt32 — LE, строки — CP1251 с проверкой длины и завершающим нулём;
битовые поля меняют только свою маску. CRC16: FFFF/A001 по 510 байтам,
из User/crc.c обеих веток; младший байт в 510, старший в 511.

Перед 0x21: подтверждение только изменённых полей, администратор 0x20,
повторное чтение и сравнение с исходником, резервный файл через CreateNew.
Файл содержит секреты, о чём сказано в диалоге выбора. Запрос
`[0,00,02,512 байт]`, ответ `[55,21,0,0]`, затем полная сверка чтением.
Потеря ответа не вызывает автоматического повторения записи.
Пароли скрыты в списке изменений; кнопки oldWriteSettings/oldConfirmWrite
заблокированы в AgentChannel. Демо хранит изменённый блок в памяти процесса.

Проверено: Release без ошибок; oldfw-write.ps1 — 93 проверки (включая
все поля, биты, длины, резерв, секреты, запись/чтение, устаревший снимок);
oldfw-read.ps1 — 70. В демо45 команда nc_agent.ps1 click oldWriteSettings
получила отказ. Реальная запись, смена пароля и чтение после неё — владельцем.


## Этап 3 — база номеров

0x2A добавляет, 0x2B удаляет; изменение — удаление и добавление после
одного подтверждения. Перед каждой операцией повторно сравнивается база,
сохраняется CSV-резерв. Счётчик проходов сбрасывается прошивкой при добавлении,
это указано в подтверждении. По завершении состав и поля сверяются чтением;
автономно меняющийся счётчик проходов исключён из сравнения.

Загрузка принимает полный CSV экспорта NextConfig. Проверяются заголовки,
длины, кодировка, метки, лимит и дубли; отображаемые поля должны соответствовать
исходным 64 байтам, чтобы не загрузить невидимые пользователю изменения.
Перед полной заменой показываются количества добавлений/изменений/удалений
и конкретные различия. 0x2D: блоки по 16 записей с индексом и количеством,
проверка каждого ответа; завершение [2] без ответа, затем чтение. Пустая база
использует [1]. Нет автоматического повтора при ошибке/обрыве.

0x28: подтверждаемое сжатие, резерв и проверка состава. В v1–v3 первый 0x2C
возвращает старый счётчик, поэтому количество запрашивается дважды; чтение
блоков последовательное, неактивные ячейки отвергаются. Демо45 имитирует
устаревшее первое количество и хранит изменения базы в памяти.

Проверено: Release без ошибок; oldfw-numbers.ps1 — 18 сценариев (включая
CRUD, CSV, много блоков, пустую базу, сжатие, дубли, отсутствие выбора,
устаревший снимок и счётчик v1–v3). Все пять кнопок получили отказ через
nc_agent.ps1 click. Реальные записи/сжатие и обрыв импорта — проверяет владелец.


## Этап 4 — сервис

0x26 отправляется один раз без ожидания несуществующего ответа; физическое
срабатывание проверяет оператор. 0x27 передаёт один байт 0/1 без ответа,
результат сверяется по DEVICE[32].bit7. Перед изменением проверяется старое
состояние. Обе операции запускаются только после подтверждения.

0x2F не просто сбрасывает настройки: user_setdefault_c1 стирает базу и
хронологию. Предварительно сохраняются BIN/CSV и показывается список изменений.
Эталонные заводские значения 45/48 взяты из обеих функций user_setdefault_c1;
для 47 значения не предполагаются и так подписаны в подтверждении.
После ответа 0 сравниваются настройки (45/48) и пустая база; доступ сбрасывается.

0x2E — один запрос [0,номер[11],начало UInt32,конец UInt32]. При отсутствии
ответа — явное сообщение об отсутствии поддержки. Ни очистки [10], ни 0x34,
ни серверных 0x40/41 нет (уточнение владельца). 0x29 тоже пуст в обеих ветках:
однократное чтение сообщает отсутствие поддержки, а не показывает выдуманный
журнал. Ответ при его наличии разбирается как длина UInt8 и CP1251-текст,
по Unit1.cpp:1081. Данные 0x29/0x2E скрыты в AgentLog.

Проверено: Release без ошибок; oldfw-service.ps1 — 14 проверок (состояние,
устаревшее подтверждение, отсутствие протокола, резерв и сброс в демо,
различия заводских настроек). nc_agent.ps1 click отклонил три пишущие кнопки;
чтение хронологии в демо45 вывело отсутствие поддержки. Реальный выход,
авторегистрация и сброс — только владельцем.
