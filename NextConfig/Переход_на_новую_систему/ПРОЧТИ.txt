Файлы для перевода старых плат ДОМОВОЙ на новую систему

Эту папку NextConfig находит сам. Оператору ничего выбирать не нужно:
кнопка «Перевести на новую систему» в окне старой платы ведёт по шагам.

v5\             плата ДОМОВОЙ NEXT v5 (старая прошивка 48), номер платы 139
  139.71.<сборка>.bin   новая прошивка (шаг 1, через старый загрузчик)
  DomovoiBoot.bin       новый загрузчик 0x32 (шаг 2)

старая_MODEM\   старая плата ДОМОВОЙ IP v1–v3, вариант MODEM (старая прошивка 45/47),
                номер платы в новой системе 140
  140.71.<сборка>.bin   новая прошивка для этой разводки: второго реле нет,
                        PA0 (CTS порта RS232) не трогается
  DomovoiBoot.bin       новый загрузчик 0x32, профиль MODEM, номер 140

Плата MINI (номер 11): новой прошивки для неё нет, перевод недоступен.

Загрузчик 0x32 работает только на микроконтроллере со 128 КБ памяти.
На другом прошивка сама откажется менять загрузчик — плата продолжит работать.

Файлы собраны в IAR из репозитория прошивки, коммит 8374224 (29.09.2026):
конфигурации Release, Release_140, загрузчик Release и Modem_Release.
