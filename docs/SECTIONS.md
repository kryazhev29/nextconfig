# Разделы NextConfig

Существующие карточки Form2 перенесены вместе с контролами и обработчиками.
Общий конструктор карточки теперь в Theme.Card; оформление сохранено.
Меню Theme.MainNavigation используется NEXT, v5 и загрузчиками.

| Было | Стало |

| Состояние | Устройство: прежние карточки связи, устройства, входов/выходов; добавлены память и фото |
| Настройки → Связь, 485 и Wiegand, Доступ | Настройки: те же поля; переключатели подразделов сверху; Сохранить / Отменить / По умолчанию внизу |

| Идентификаторы | Пользователи: память, импорт/экспорт, очистка с прежними обработчиками; импорт/экспорт NEXT остаются существующими заглушками |
| Объект | Сервис → Объект: все сведения и обе кнопки |

У NEXT расписания задаёт сервер — пункта нет. В v5 просмотр расписаний берётся
из того же 0x20, без новых команд и без записи. Неподдерживаемый журнал v5
обозначен на странице устройства; пустого раздела нет. gchrono не добавлен.
В загрузчике доступно только «Устройство», где используется прежний frmFW.

## Чтение полного пакета NEXT

ConfigSnapshot показывает ровно последний прочитанный пакет, включая резерв
и CRC. Редактор настроек его не подменяет. Все 512 байт покрыты один раз;
раскладка — NEXT structures.h:465–499. ПИН и параметры оператора изначально
скрыты. «Перечитать настройки платы» использует существующий GetConfig.

## Перевод старой платы без кнопки

| Команда SLGT | Запрос / ответ | Источник |
|---|---|---|
| 0x04 | Тело запроса AA 04 01; ответ 55 04, затем перезапуск в загрузчик | v5 User/user_fun.c:409–418; Unit1.cpp:2699 RebootinBootClick → ResetDevice(1) |
| 0x00 | После перезапуска работает существующее различение прошивки и загрузчика | OldFirmware.IsFirmware / IsBootloader, источники указаны в коде |

0x04 не входит в допуск чтения. Единственный прикладной вызов — обработчик
кнопки после подтверждения. Затем Form1 запускает повторный поиск, открывает
экран загрузчика, использует clBoot.UploadLegacy и далее Form2.OfferBootReplace.
Если подтверждение перезапуска потерялось, показывается ошибка с предложением
подключиться заново; автоматического повтора 0x04 нет.
Протокол фото и ограничения v5: [PHOTO_USB.md](PHOTO_USB.md).
Команды исходного этапа чтения: [oldfw-v5-read.md](oldfw-v5-read.md).

## Проверено

- Release, без ошибок. Предупреждения BC42030 существовали до этих изменений.
- 70 проверок чтения v5, 195 проверок смещений исходников, 28 проверок фото,
  10 проверок полного пакета/кадра перехода и запрета 0x04 в чтении.
- Все доступные разделы --demo, --demo:oldfw48, --demo:oldboot, --demo:oldfw,
  --demo:boot; масштабы 100% и 125%. Демо-ключи --demo-dpi=96/120 фиксируют
  размеры независимо от системного DPI; --demo-laptop ограничивает окно
  1366×728 (запас под панель задач на экране 1366×768).
- При недостатке ширины те же карточки состояния располагаются вертикально.
  Горизонтальной прокрутки нет; нижние поля доступны вертикальной прокруткой.
  Длинные диалоги используют прокрутку и закреплённые кнопки.
- Старые номера: сохранение CSV из нового раздела, 35 демозаписей.
- Фото NEXT: снимок, выбор папки, JPEG и превью, потеря/повтор, пустая очередь;
  отключённые кнопки при обновлении, подсказка при неактивном RS-485.
- Полный перевод в демо: подтверждение/отмена 0x04, шаг 1, повторный вход,
  предложение шага 2, пробная передача загрузчика, два подтверждения замены,
  повторный вход с версией 0x32. Использованы существующие BIN только в демо.

## Не проверено и вопросы владельцу

Реальный COM-порт не открывался. Камера, USB с отключением питания/кабеля,
сохранение очереди в памяти платы и настоящий перевод системы требуют стенда
с владельцем. Прошивки не изменялись.

В эталонной v5 фото по USB отсутствует: 0x30 возвращает 250, 0x31/0x32 пусты.
Архив журнала также недоступен, альтернативный серверный журнал старого CFG
не добавлен по согласованному ограничению.

Сборка v5 оставлена исходными кодами builddate/buildtime. Старый CFG тоже
выводит их как четыре десятичных цифры (Unit1.cpp:2365); источник значений —
board.h:33–35 и user_fun.c:1244–1245. Для вывода календарной даты нужен
подтверждённый формат этих кодов. Есть ли у владельца описание/пример сборки
с известной датой? Это не мешает чтению.

v1–v3: проверка исходников подтверждает совпадение смещений трёх структур с v5;
это не проверка совместимости команд и не поддержка старых версий.
